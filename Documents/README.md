## 🔄 Version Control

### Naming Conventions
- **Current files**: `kebab-case.md` (no version suffix)
- **Archived files**: `Original_Name.md` or `name-v1.md`
- **Session files**: `YYYY-MM-DD-description.md`

### File Headers
All documentation includes version headers:
